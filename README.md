# Customer Research & Market Insights Analytics

## Project Overview

This project focuses on analyzing customer shopping behaviour to uncover meaningful insights about customer demographics, purchasing patterns, satisfaction levels, spending behaviour, and product preferences.

The analysis was conducted as part of a Data Science pipeline for a market research and business consulting company. The goal was to transform raw customer shopping data into actionable business insights that can support better decision-making, improve customer experience, and optimize marketing strategies.

The project uses the **shopping_trends.csv** dataset and applies data inspection, data cleaning, exploratory data analysis (EDA), visualization, and business interpretation.

# Data Science Pipeline

## Section 1: Data Inspection

The first stage involved understanding the dataset structure and identifying potential data quality issues.

### Tasks Performed:

- Imported required Python libraries
- Loaded the shopping trends dataset
- Displayed the first and last rows
- Checked dataset dimensions
- Reviewed column names
- Examined data types
- Identified missing values
- Checked duplicate records
- Generated descriptive statistics

This step provided an overview of the dataset and prepared it for further processing.

---

# Section 2: Data Cleaning

Data cleaning was performed to improve the accuracy and reliability of the dataset.

### Cleaning Steps:

## Removing Duplicate Records

Duplicate customer records were identified and removed to prevent repeated entries from affecting analysis.

---

## Handling Missing Values

Missing records were removed to ensure the dataset used for analysis contained complete information.

---

## Standardizing Gender Values

Gender entries were cleaned by:

- Removing unnecessary spaces
- Converting values into a consistent format

---

## Standardizing Customer Locations

Location values were cleaned by removing unnecessary spaces and improving consistency.

---

## Converting Purchase Amount

Purchase Amount values were converted into numerical format to support statistical analysis.

---

## Removing Invalid Ages

Customer ages were filtered to keep only realistic values between 18 and 100 years.

---

## Standardizing Review Ratings

Review ratings were converted into numerical values for accurate satisfaction analysis.
